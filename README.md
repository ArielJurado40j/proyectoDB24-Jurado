# proyectoDB24-Jurado-Palenque
Proyecto integrador de Base de Datos.


# Descripción
Proyecto desarrollado para la cátedra Base de Datos.

# Objetivo
Diseñar e implementar una base de datos relacional que permita organizar y administrar la información de SIMA Centro de Diagnóstico.

# Características
- Modelo de datos relacional.
- Tablas relacionadas mediante claves primarias y foráneas.
- Normalización hasta la Tercera Forma Normal (3FN).
- Integridad referencial.
- Organización de la información.

# Tecnologías utilizadas
- MySQL 8.
- MySQL Workbench.
- Laragon.
